## Smartlead Custom Fields for Xoxoday Campaigns

Upload these inside each lead's `custom_fields` object — they become merge tags in your copy.

| Field Key (upload) | Merge Tag | Notes |
|---|---|---|
| `job_title` | `{{job_title}}` | e.g. "VP People", "Director RevOps" |
| `personalized_line` | `{{personalized_line}}` | Company-specific opener (LinkedIn post, recent funding, news) |
| `product_angle` | `{{product_angle}}` | `empuls` / `plum` / `compass` / `loyalife` — lets you segment |
| `headcount` | `{{headcount}}` | Round number for ROI math in copy |
| `countries` | `{{countries}}` | e.g. "5 countries across APAC + EMEA" |
| `hris` | `{{hris}}` | e.g. "Workday", "SAP SuccessFactors" |
| `tier` | `{{tier}}` | `1`, `2`, or `3` |
| `sender_first_name` | `{{sender_first_name}}` | Overrides default sender tag if needed |

> ⚠️ Smartlead merge tags are **case-sensitive and snake_case**. Upload keys exactly as you want to reference them.

## Converting These Templates to Smartlead `email_body` HTML

Each plaintext block above becomes `<p>` tags in the API payload. Example:

```json
{
  "subject": "{{first_name}}, a question about recognition at {{company_name}}",
  "email_body": "<p>Hey {{first_name}},</p><p>Most People teams at {{company_name}}'s size are running recognition on a patchwork…</p><p>Open to a 15-min walkthrough?</p><p>{{sender_first_name}}<br/>Xoxoday</p>",
  "variant_label": "A"
}
```
